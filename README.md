# Sistema "Justo para Vos" - YPF S.A.
## Trabajo Práctico Integrador - Organización Empresarial
**Universidad Tecnológica Nacional (UTN) - Tecnicatura Universitaria en Programación**

### Integrantes:
* Francisco Rodriguez

### Descripción del Proyecto:
El sistema "Justo para Vos" integra tecnología wearable (pulseras RFID/NFC) y telemetría en tiempo real dentro de las estaciones de servicio de YPF S.A., optimizando la gestión de personal, la trazabilidad de despachos y reduciendo discrepancias financieras.

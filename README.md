# Sistema "Justo para Vos" - YPF S.A.
## Trabajo Práctico Integrador - Organización Empresarial
**Universidad Tecnológica Nacional (UTN) - Tecnicatura Universitaria en Programación**

### Integrantes:
* Francisco Rodriguez

### Descripción del Proyecto:
El sistema "Justo para Vos" integra tecnología wearable (pulseras RFID/NFC) y telemetría en tiempo real dentro de las estaciones de servicio de YPF S.A., optimizando la gestión de personal, la trazabilidad de despachos y reduciendo discrepancias financieras.

##Declaración de Transparencia en el Uso de Inteligencia Artificial (IA)
En el desarrollo del presente Trabajo Práctico Integrador, se ha empleado un asistente de inteligencia artificial como una herramienta de colaboración técnica y apoyo metodológico. Con el fin de garantizar la integridad académica y la autoría intelectual del proyecto

###Formulación de Consultas (Prompts): 
Las interacciones se estructuraron bajo un enfoque de consulta y correccion del modelado sistémico (TGS), la integración tecnológica del sistema "Justo para Vos" (telemetría y wearables) y la generación de artefactos formales (diagramas BPMN, matriz FODA, cronograma de desarrollo y diccionario de datos)
###Validación y Corrección Humana: 
Ningún resultado fue incorporado de forma automática. Se adaptó el contenido a la realidad operativa de YPF S.A, se acoto y adapto los resultados para el sistema propuesto.
